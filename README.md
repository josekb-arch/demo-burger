# All Star Burgers — demo replica

Scroll-driven demo (not a real restaurant site): Three.js burger that comes apart on scroll, a procedural GAME DAY COMBO box whose lid closes, THE LINEUP menu, sides and the closing section.

Stack: Three.js r170 + GSAP ScrollTrigger + Lenis, all vendored in `vendor/`. `prefers-reduced-motion` (or no WebGL) gets a static, readable page.
